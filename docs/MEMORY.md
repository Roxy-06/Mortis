# Persistent trading memory

Mortis stores paper decisions in `decisions` and durable episode outcomes in `memory_episodes`. Market states are numeric JSON feature vectors; similarity uses standardized Euclidean distance over common finite features. Retrieval is restricted to the same side and feature-schema version, ignores counterfactuals as direct evidence, excludes episodes inside the configured time gap, and applies exponential age decay.

The summary reports neighbor count (`n`), effective sample size, weighted average R, a time-weighted win rate shrunk toward the global resolved rate, dispersion, a deterministic bootstrap interval, and whether effective sample size meets `memory.min_n`. The system filters small samples as insufficient rather than treating them as reliable evidence. Standardization statistics are persisted in `memory_feature_stats`; startup restores episode counts from SQLite and decision-time additions update statistics incrementally. Use `python -m tools.rebuild_memory` to rebuild those statistics from persisted vectors.

`memory.mode` supports `off`, `advisory` (default), and `gate`. Advisory mode records analogs but does not alter an action. Gate mode only acts when sample sufficiency is met: it can veto or reduce size, never increase size or leverage. Stops and targets remain unchanged. Counterfactual episodes are labeled and can be excluded from API queries; they are not mixed into live memory similarity.

Lessons are generated by explicit rules and are descriptive hypotheses. They are never used as numeric model inputs. Outcome labels and R are evidence about the paper simulation, not causal explanations.

## Configuration

| Setting | Default | Meaning |
|---|---:|---|
| `memory.mode` | `advisory` | Whether memory is off, descriptive, or a conservative gate |
| `memory.k` | `20` | Maximum nearest episodes returned |
| `memory.min_n` | `30` | Minimum effective history before gate action |
| `memory.min_gap_bars` | `24` | Minimum time separation in strategy bars |
| `memory.half_life_days` | `90` | Exponential time-decay half-life |
| `memory.prior_strength` | `20` | Shrinkage weight for global win rate |
| `memory.veto_gap` | `0.10` | Clear shortfall threshold for veto |
| `memory.min_size_multiplier` | `0.5` | Lower bound for memory-driven sizing reductions |

## Limits

- Memory does not create a profitable edge and cannot make a reliable claim from few samples.
- Similarity depends on the recorded feature set and its schema version. Feature changes require a version bump; incompatible history is not silently mixed.
- The confidence interval is bootstrap-based and is not a guarantee of future returns.
- Counterfactuals are simulations with recorded assumptions, not realized fills.
- Rule-based lessons are not proof of why a trade won or lost.
- Model training and promotion are separate. An active model requires the existing time-ordered validation, final-holdout evidence, and explicit paper-trial approval.
